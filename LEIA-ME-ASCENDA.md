# ASCENDA — protótipo jogável
**Da ideia ao império.**

Esta é uma adaptação do jogo acadêmico original, preservando a base HTML5/JavaScript/Canvas, os mapas, os sprites, a personalização de personagem, a exploração dos andares, os diálogos, os quizzes e o salvamento local.

## Como jogar localmente
1. Extraia o arquivo ZIP.
2. Abra a pasta do ASCENDA e procure `index.html`.
3. Se o navegador bloquear recursos ao abrir o arquivo diretamente, publique a pasta do ASCENDA em um host estático como Netlify Drop, ou use um servidor local simples.
4. No celular, é mais fácil abrir a versão hospedada num site estático.

## História
A empresa fictícia Horizonte está em crise. O jogador conversa com 12 profissionais e aprende a investigar clientes, equipe, finanças, mercado, processos, qualidade, ética e crescimento. O documento `ASCENDA_HISTORIA.md` descreve a premissa, os personagens e as próximas etapas.

## Testes
Com Node.js instalado, na raiz do repositório:
```bash
npm test
```

## Observação
Esta versão já adapta a narrativa e as perguntas, mas ainda não inclui um simulador financeiro ramificado completo. Alguns letreiros dentro das imagens dos mapas ainda podem mostrar a identidade visual original e devem ser atualizados numa etapa artística posterior.
